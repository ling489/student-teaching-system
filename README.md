# student‑teaching‑system 学生教学管理系统
 前后端交互练习项目，借助Cloud Code生成基础代码，自主排查调试，解决联调遇到的各类问题
 ## 📖项目简介
 本项目是教学数字平台后台管理系统，属于前后端分离实训项目。
 可以实现不同角色账号登录，分配权限，完成学生、课程、考勤等相关数据的管理。
 ## 🛠️用到的技术栈
 - ✅前端：HTML5、CSS、JavaScript、Vue3、Element‑Plus、ECharts（全部CDN引入，不需要npm构建打包）
 - ✅后端：Java、SpringBoot、MyBatis、Maven、JDK
 - ✅数据库：MySQL（Navicat进行数据库可视化管理）
 ## 🐛调试踩坑记录
 ### 1. 前后端联调接口返回404
 - 现象：前端、后端可以各自独立启动运行，前端调用后端接口返回404
 - 问题分析：前端请求URL与后端定义的接口路径不匹配，后端找不到对应的接口资源
 - 解决方案：核对并修正接口地址，重启前后端服务
 - 结果：接口请求成功，前后端可以正常通信
 ### 2. 后端无法接收前端传递的参数
 - 现象：接口可以请求成功，但是后端获取不到前端提交的数据，新增、提交等功能异常
 - 问题分析：前后端传参格式不一致
 - 解决方案：核对请求头与传参格式，调整对应代码
 ### 3. 后端启动提示端口占用
 - 现象：后端服务启动失败，提示端口被占用
 - 问题分析：之前运行的后端进程没有关闭，占用了端口
 - 解决方案：结束占用端口的进程，重新启动后端服务
 ## ✨主要实现功能
